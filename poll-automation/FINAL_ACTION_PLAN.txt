TROUBLESHOOTING IF NEEDED:
================================================================================

Issue: Blank page when opening http://localhost:5173
Solution:
  1. Check browser console (F12) for errors
  2. Wait another 30 seconds
  3. Verify Backend is running: curl http://localhost:3000
  4. Verify Frontend is running: curl http://localhost:5173

Issue: Services don't start
Solution:
  OPTION A: Restart your computer
    - Clears any system-protected processes
    - Fresh start ensures clean state
    - Then re-run .\START-ALL-SERVICES.ps1

  OPTION B: Run as Administrator
    - Right-click PowerShell → Run as administrator
    - cd "c:\Users\ADITYA\Desktop\NLP\poll-automation"
    - .\START-ALL-SERVICES.ps1

Issue: Port already in use
Solution:
  Find what's using the port:
    netstat -ano | findstr :<PORT_NUMBER>
  Then kill the process:
    taskkill /PID <PROCESS_ID> /F

Issue: MongoDB not connecting
Solution:
  1. Verify MongoDB is running: netstat -ano | findstr :27017
  2. If not showing, start MongoDB separately:
     .\RUN-MONGODB.ps1
  3. Wait 10 seconds, then start other services
